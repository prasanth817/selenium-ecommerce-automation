# Selenium E-Commerce Automation

## Overview
This project automates key user workflows on the SauceDemo e-commerce website using Selenium WebDriver and Python. 

## Technologies Used
- Python
- Selenium WebDriver
- ChromeDriver

## Test Scenario
- Launch Chrome browser
- Open SauceDemo website
- Login with valid credentials
- Verify successful login
- Add "Sauce Labs Backpack" to the cart
- Verify cart badge
- Open the shopping cart
- Verify the correct product is present
- Remove the product from the cart
- Verify the cart is empty
- Close the browser

## Selenium Concepts Used
- Explicit Waits (`WebDriverWait`)
- Expected Conditions
- Element Locators (`ID`, `CLASS_NAME`)
- Assertions
- Click Actions
- Keyboard Input (`send_keys`)
